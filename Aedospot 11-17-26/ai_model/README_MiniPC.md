# Aedospot deployment\n\nKeep all model files in this folder. Install requirements with `pip install -r requirements.txt`.\nUse `from prediction import AedospotPredictor`; load the predictor once and call `predict(daily_df)` with the latest 30 consecutive daily records.\nRequired columns: date, rainfall, tmean, rh, wind_speed.\nPredictions use 30 days ending before the target month. Do not pass incomplete days or fill missing values with zero.\n
